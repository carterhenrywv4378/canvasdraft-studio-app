## Overview

CanvasDraft Studio provides a drawing workspace that runs directly inside a web browser. Built with vanilla JavaScript and a custom HTML5 canvas rendering engine, it supports creating and modifying visual scenes without the need for a separate desktop installation.

Drawing data is arranged through a scene graph, giving the application a structured way to manage its elements. An undo/redo history stack supports experimentation and revision as work progresses. The project is intended both for people who want a lightweight online drawing application and for developers exploring a canvas project based on uncomplicated web technologies.
